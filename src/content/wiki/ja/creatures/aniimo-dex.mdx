アニモ（Aniimo）の図鑑を築き上げることが、Pawprint Studio が手掛ける次世代オープンワールド・生き物を[捕まえる](/ja/creatures/aniimo-catching/)ARPG「アニモ」における冒険の中心だ。あなたはパスファインダー（Pathfinder）として広大なエーデル（Idyll）大陸を探索し、魔法の生き物たちを見つけ、絆を結び、図鑑に記録していく。従来のターン制の捕獲系ゲームとは異なり、アニモはリアルタイムバトルと、独自の絆システム「ツワイン（Twine）」によって、野生の生き物との関わり方を根本から変えている。コミュニティではこの図鑑を **Anilog** と略して呼ぶことが多く、**Aniilog** という表記も見られる。一方、公式サイトでの呼称は **Aniimo Index** だ。本ガイドではこれら3つの名称を同じ意味で使う。公式の Index では発売時のラインナップとして、全エントリーの属性・ロール・基礎ステータス・スキル一覧がすでに公開されており、本ガイドでは図鑑の仕組み、判明済みの全生き物、そして絆のメカニクスを2026年9月16日の発売に向けてまとめていく。

## Anilogとは？ Aniilog、Aniimo Index、図鑑の解説

「aniimo anilog」で検索している人も「aniimo dex」で検索している人も、探しているものは同じ——発見して絆を結んだすべての生き物を記録するコレクションログだ。名称はコミュニティで3つの表記に定着しているが、すべて同じシステムを指す。

| 名称 | 目にする場所 |
| :--- | :--- |
| **Anilog** | コミュニティの動画や大半のプレイヤー間の議論 |
| **Aniilog** | ファンWikiやデータベース（iが2つ） |
| **Aniimo Index / Encyclopedia** | wiki.aniimo.com での公式呼称 |

2点ほど誤解を解いておきたい。まず、Anilogは**独立したアプリではない**——ゲーム内に存在する機能であり、どのストアにも公式のコンパニオンアプリは存在しない。次に、図鑑のエントリーは単なるチェックリスト以上のものを記録する。フォルム違いのコレクション進捗やコンプリートボーナスがエントリーごとに記録されるため、Aniilogのページを完成させる（例えば[Nimbiの全フォルム](/ja/guides/aniimo-forms/)を収集する）ことには、捕獲そのもの以上の報酬がある。

## ツワインシステムとアニモ図鑑の関係

アニモの図鑑はただの静的な百科事典ではない——出会った生き物たちとのリアルタイムの絆を映すものだ。本作を際立たせる中核メカニクスが「ツワインシステム」である。生き物を弱らせてアイテムを投げるだけではなく、パスファインダーはエーデル大陸の魔法の獣たちと深い絆を結ぶ。

ツワインシステムを通じて生き物が図鑑に加わると、メニューから眺めるだけでは終わらない。公式のゲームプレイ公開情報によれば、ツワインシステムでは絆を結んだ生き物の視点そのものを体験し、テンポの速いリアルタイムアクションバトルでその固有のアビリティを駆使できる。つまり、アニモの図鑑完成は「全部捕まえる」だけでなく、フィールドで展開できる物理・属性アビリティの幅広いロスターを戦略的に構築することでもあるのだ。図鑑UIがこの絆レベルやアビリティ解放をどのように管理するのかはまだ不明だが、深く統合された成長システムになることが予想される。

## Aniimo Indexで判明している生き物

トレーラーからの推測の時代は終わった——公式の Aniimo Index では、発売時の全94エントリー（No.001からNo.093、加上2つのティーザー枠）の属性、ロール、基礎ステータス、生息地、完全なスキル一覧が公開されている。ロースターからいくつかピックアップしてみよう。

| 生き物 | 公式No. | 属性 / ロール |
| :--- | :---: | :--- |
| [Emberpup](/ja/creatures/aniimo-emberpup/) | 001 | 炎 / DPS |
| [Irisal](/ja/creatures/aniimo-irisal/) | 012 | 草 / DPS |
| [Helmut](/ja/creatures/aniimo-helmut/) | 062 | 闇 / Breaker |
| [Nimbi](/ja/creatures/aniimo-nimbi/) | 018 | 風 / Support |

No.001から未公開のティーザー枠2つまで、すべてのエントリーが[アニモ全生き物一覧](/ja/creatures/aniimo-creatures-list/)でプロフィールを確認でき、最初のイベントレジェンドである[Irisalis](/ja/creatures/aniimo-irisalis/)には専用ページも用意されている。一部のアニモには別フォルム（NimbiのCloudmist Formなど）が存在する——詳しくは[アニモ フォームガイド](/ja/guides/aniimo-forms/)を参照してほしい。

これらの生き物を見つける鍵となるのは、エーデル大陸の多様なバイオームの探索だ。特定のダンジョンやオープンワールドのボスを守る強い縄張り意識を持つアニモもいれば、平原を群れで徘徊する個体もいる。

## アニモ図鑑の追跡と完成

 massive なオープンワールドARPGでアニモの図鑑を完成させるには、ジャンルの旧来作とは違うアプローチが必要だ。アニモはリアルタイムバトルを採用し、ランダムエンカウントが存在しないため、図鑑作りは探索、隠密、環境への意識に大きく依存することになる。

開発者のショーケースから、パスファインダーが新しいエントリーを追跡・捕獲する方法はおそらく次の通りだ。

| ゲームプレイメカニクス | 図鑑への予想される影響 |
| :--- | :--- |
| **オープンワールドの出現** | 生き物は世界に自然に現れる。図鑑完成はバイオーム探索が鍵。 |
| **リアルタイムエンゲージメント** | メニュー操作ではなく、アクションバトルで能動的に戦い、 dodgeし、絆を結ぶ必要がある。 |
| **ツワインによる絆** | 捕獲はバトル中またはバトル後の繋がり構築に紐づき、独自の捕獲ミニゲームやメカニクスが加わる。 |
| **ファンタジークエストと協力プレイ** | 一部のレアなアニモの図鑑エントリーは、マルチプレイヤーでの連携が発見や撃破に必要になる可能性がある。 |

エーデル大陸を旅する中で、すでに絆を結んだアニモを使って飛行や泳ぎなどで環境を移動し、レアな図鑑エントリーを含む孤立したエリアへのアクセスが開けていくだろう。

## アニモ図鑑の進化と成長

生き物を捕まえるゲームの定番である進化についても、公式の Index が図鑑の全生き物の進化ツリーを公開している。レベル上げはターン制バトルではなくリアルタイムバトルに紐づいており、分岐する系統も複数ある——例えばNimbiは最終段階でDreapleかTurboに分岐する。

アニモの図鑑エントリーは、受け身のターン制バトルで経験値を得るのではなく、リアルタイムのコンボ参加、固有の属性アビリティの使用、オープンワールドの遭遇を生き延びることで進化していくはずだ。分岐する進化ルート、隠された条件、次の段階のトリガーに必要な特定アイテムを持つ生き物も存在すると大きく期待されている。本作にはファンタジークエストや[マルチプレイヤー](/ja/guides/aniimo-multiplayer/)の協力プレイが組み込まれているため、進化に他のパスファインダーとのトレードや特別なワールドイベントへの参加が必要になる場合すらあるかもしれない。

2026年のフルリリースが近づくにつれ、Pawprint Studio から進化ツリーの正確な仕組み、ステータスの伸び方、ツワインで絆を結んだ仲間のレベル上限について発表される見込みだ。

## よくある質問

### アニモの図鑑とは？

アニモの図鑑は、パスファインダーがエーデル大陸で出会い、絆を結んだ魔法の生き物を記録するゲーム内のコレクション図鑑だ。ツワインシステムを通じて、収集した生き物、そのアビリティ、絆レベルが記録されていく。

### アニモにおけるAnilog（Aniilog）とは？

Anilogは、ゲーム内生き物図鑑のプレイヤー間での愛称——本ガイドで「アニモ図鑑」と呼んでいるシステムと同じものだ。ファンWikiではAniilog（iが2つ）という表記も見られ、公式サイトでは Aniimo Index と呼ばれる。3つの名称はすべて同じコレクションログを指す。

### Anilogはアニモの独立したアプリ？

いいえ。Anilogはアプリではなく、アニモ本体のゲーム内に存在する図鑑機能だ。公式のコンパニオンアプリは存在せず、公式チャンネルはゲーム本体、aniimo.com ウェブサイト、そして wiki.aniimo.com の公式Wikiだ。

### 発売時点でアニモ図鑑には何体の生き物が収録される？

公式の Aniimo Index では現在、2026年9月16日の発売を前に94体（No.001–No.093 plus ティーザーエントリー2枠）がリストされており、ロースターは発売後も拡大していくと見込まれる。[生き物一覧](/ja/creatures/aniimo-creatures-list/)で判明済みの全エントリーを追跡している。

### アニモでの生き物の捕まえ方は？

捕獲はツワインシステムに依存しており、単にアイテムを投げるのではなく、生き物との絆を結ぶことが中心となる。生き物とリアルタイムアクションバトルで交戦し、そのアビリティを駆使し、視点を共有するメカニクスを活用していく。

### 現時点でアニモに参戦が確定している生き物は？

公式の Aniimo Index では、HelmutやEkoからNo.001–093の全ラインナップまで、94体の生き物の属性、ロール、ステータス、スキル一覧が公開されている。全員のプロフィールは[生き物一覧](/ja/creatures/aniimo-creatures-list/)で確認できる。数値は発売前に変わる可能性はある。

### アニモの生き物には従来型の進化がある？

はい。アニモの生き物には進化系統と成長システムが存在すると予想されている。具体的な方法は未発表だが、進化はリアルタイムバトルの経験、絆レベル、場合によっては特別なオープンワールドイベントに紐づく可能性が高い。

### アニモはマルチプレイヤーゲーム？

はい。アニモには協力プレイやマルチプレイヤーのファンタジークエストが搭載されている。他のパスファインダーと一緒にオープンワールドを探索し、リアルタイムバトルを繰り広げ、アニモ図鑑を完成させることができる。
