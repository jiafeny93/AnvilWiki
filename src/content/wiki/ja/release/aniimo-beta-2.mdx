## アニモベータ2：基本情報まとめ

アニモベータ2は、Pawprint Studio開発・FunPlusパブリッシュによる、基本プレイ無料の生き物テイム系アクションRPG「アニモ」の2回目となる大型クローズドテストだ。2025年のXbox Games Showcaseでの正式発表と[第1回クローズドベータ](/ja/release/aniimo-beta/)に続いて実施され、Prismanaの光るレア個体や継承システムをはじめ、今ではアニモと強く結びつけて語られるシステムがいくつも明らかになった。

重要なのは、これがオープンベータではなく**招待制のクローズドテスト**だったという点だ。参加には招待を受けるか、公式のベータチャンネルからの登録が必要で、テストはすでに終了している。

| 項目 | 確定情報 |
|---|---|
| テスト名 | 第2回クローズドベータ（コミュニティでの略称：アニモベータ2、アニモクローズドベータ2） |
| 実施時期 | 2026年1月に実施。正確な開始・終了の期間は公式チャンネルで発表済み |
| 参加形式 | クローズドベータ――招待制で、誰でも参加できるわけではない |
| モバイル配信 | Google Playのテストアプリ「Aniimo Beta」 |
| 開発元 / パブリッシャー | Pawprint Studio / FunPlus |
| 現在の状況 | 終了。公式Wiki（wiki.aniimo.com）にベータ当時のデータが掲載されている |
| グローバルリリース | 2026年9月16日に決定 |

ゲームは未発売のため、第2回クローズドベータでデータマイニングや公開によって判明した情報（アイテム名、ショップ通貨、イベント構成など）は、リリース時には変更される可能性があるとして扱うべきだ。

## アニモベータ2の参加方法と今後のテスト情報の入手方法

第2回クローズドベータへの参加は、各ストアの一般登録ページではなく公式チャンネル経由で行われた。Androidでは**Google Playのテストアプリ「Aniimo Beta」**からの登録形式で、これがモバイルのテストフェーズにおける確定した配信方法だ。招待やキーの配布はアニモの公式Discordや各種SNSアカウントで発表され、過去のテスト参加者や公式コミュニティで積極的に活動していたプレイヤーの方が招待を受けやすいと一般的に見られていた。ただし、FunPlusとPawprint Studioが正確な選考基準を公開したことは一度もない。

今後のテストやリリース版へのアクセスを狙っているなら、実践的なチェックリストはシンプルだ。

1. **公式Discordに参加する**（discord.gg/aniimo）――テストの告知、キー配布、フィードバック調査はまずここで投稿される。
2. 公式サイト（aniimo.com）と自分の利用プラットフォームで**事前登録**する――当サイトの[事前登録ガイド](/ja/release/aniimo-pre-register/)で全ストアの手順を解説している。グローバルの事前登録者数はすでに500万人を突破している。
3. Androidプレイヤーなら**Google Playのベータアプリを注視**し、ストア掲載情報の通知も有効にしておこう。
4. ショーケース映像の公開やテスト期間の情報に備えて、X・YouTube・Instagramの**@Aniimo_ENをフォロー**する。

なお、サードパーティのサイトがベータへのアクセスを提供できることは一切ない。よそで見かける「アニモベータ2の無料キー」のオファーは、すべて詐欺として扱うべきだ。

## アニモベータ2でテストされた新システム

第2回クローズドベータは単なるストレステストではなかった。今のコミュニティがアニモをどう語るかを形作ったメカニクスがいくつも導入されている。公式の発表とベータ当時の資料をもとに、主要なシステムをまとめよう。

| システム | 機能 | ベータ限定の備考 |
|---|---|---|
| Prismana個体 | 特殊な天候「Prismana Flow」の際に出現する可能性がある、虹色系の光るレア個体（カラーバリエーション） | プレイヤー側へ誘導することが可能だった。個体の色はLumin Crystalショップのアイテム「Shimmering Reverie」で振り直せた |
| 継承システム | 仲間のアニモが、パスファインダーのキャラクターステータス（クリティカル率、HP、防御力など）の一部を継承する | ベータで確認できた正確な継承率は、リリース時に調整される見込み |
| Promiseイベント | 期間限定のベータイベント：Prismana Promise、Bound Promise、Reunion Promise | リリース時に同じ形で復活するかは未定 |

[Prismanaシステム](/ja/guides/aniimo-prismana/)は、いわゆる「色違い」狩りのアニモ流アプローチだ。ベータで示されたのは、単にエンカウントを振り直すよりも一段と能動的なループで、Prismana Flowの天候中にスポーンへ影響を与え、後からLumin Crystalショップで色を再カスタマイズできるというものだった。一方、[継承システム](/ja/guides/aniimo-inherit-system/)は、あなたのキャラクタービルドをリアルタイム戦闘での仲間の性能に直結させる仕組みで、ARPG的な成長と生き物コレクター的なデザインを意図的に融合させた設計になっている。

上記のアイテム名、ショップ通貨、イベント報酬は、すべて**ベータ当時の情報**として扱ってほしい。Lumin Crystalショップの経済、Shimmering Reverieの入手手段、イベント構成は、リリース版では見た目が変わっている可能性がある。

## アニモベータ2のデータは引き継がれる？

アニモベータ2のデータ（捕まえたアニモ、レベル、アイテム、イベント報酬）が正式版へ引き継がれるという公式発表は存在しない。クローズドベータの標準運用と同様、データは完全にリセットされると想定しておくのが無難で、ベータアカウントはアドバンテージではなく使い捨てのテスト環境と考えるべきだ。

テスター限定報酬についても同じことが言える。Pawprint StudioやFunPlusがリリースに向けたベータ参加報酬を明示的に発表しない限り、何も引き継がれないと考えよう。不安な場合は、公式Discordかwiki.aniimo.comを確認してほしい。この2つが引き続き正確な情報源だ。
