- question: フォームでステータスは変わる？

アニモ（Aniimo）には複数の顔を持つものがいる。既に公開されている94種のロスター之外に、公式Aniimo Indexにはひっそりと第二のページ群が存在する。それが**フォーム**だ。バイオームに適応したバリエーションで、たとえば[Nimbi](/ja/creatures/aniimo-nimbi/)のCloudmist Formのように、生き物の見た目や戦い方、出現場所まで変える。本ガイドでは公式公開データをもとにこのシステムを解説し、[Prismana](/ja/guides/aniimo-prismana/)（光るレア個体）や進化との違いを整理したうえで、現時点で判明しているフォームを追跡する。

なお、アニモはまだリリースされていない（グローバルリリースは2026年9月16日に確定済み）。そのため、公式インデックスデータ以外の要素——入手方法やMorph Orbなど——はベータおよびコミュニティのデータに基づいており、変更される可能性がある。

## フォームとは何か、なぜ存在するのか

アニモの生き物は世界のバイオームに適応する——これはコミュニティデータベース由来の解釈だが、公式Indexのデータもこれを裏付けている。すべての種には**Basic Form**が存在し、一部の種は追加のフォームを公開している。各フォームは独立したIndexエントリーとして、独自の属性リスト、生息地、ページを持つ。公開済みの数値が示すパターンは次のとおり：

- **ステータスは共通。** 同じ種のフォームはすべて基礎ステータス、ロール、体重帯、特性が同一。フォームは水平方向の変化であって垂直方向ではない——見た目の代わりに強さを犠牲にするようなことはない。
- **場合によっては第二属性。** Basic Formにはない属性を追加できる場合があり、これこそがフォームを単なる見た目変更ではなく戦略的に興味深いものにするポイントだ。
- **独自の出現ロジック。** フォームは種の生息地をそのまま使うこともあれば、完全に別の場所へ移ることもある。

## 実例解説：Nimbiの4フォーム（公式データ）

[Nimbi](/ja/creatures/aniimo-nimbi/)は完全に公開済みのショーケースだ。公式Indexには4つのエントリーが掲載されており、いずれもNo.018、Wind/Support、基礎ステータス合計442、特性は[Shrouded in Mist]：

| フォーム | 属性 | 生息地 | 備考 |
| :--- | :--- | :--- | :--- |
| **Basic Form** | 風 | Nimbus Fields, The Argent Strait | 一般的な雲羊の見た目 |
| **Cloudmist Form** | 風 | Nimbus Fields | 金色がかった毛；Sunny Daisyに引き寄せられる |
| **Rainstorm Form** | 風 + 雷 | Nimbus Fields | 水を含んだ通電性の毛 |
| **Plateau Form** | 風 + 氷 | Driftwise Meadow | 生息地を移すフォーム——まったく別のバイオーム |

この表は二度読んでほしい——1種の中にシステム全体が詰まっている。ステータスはどこも同じ、雷と氷の属性はフォームごとに現れたり消えたり、Plateauに至っては出現ゾーンまで変わる。基礎キットの戦闘運用については[Nimbiの生き物ページ](/ja/creatures/aniimo-nimbi/)を参照してほしい。

## ソース間でのフォーム名表記について

フォーム名はまだコミュニティ全体で統一されておらず、検索結果でも表記の揺れが見られる：

- 公式Indexでは**Rainstorm**と**Plateau**が公開されている——ただし公式ページデータには旧表記の「Thunderstorm」タグも残っており、一部のファンWikiはいまだRainstormをThunderstormと表記している。
- 一部のデータベースはPlateauを**High Altitude Form**と呼んでいる。

当サイトは公式Indexの名称に従い、代替表記も併記することで、どちらの表記で検索しても辿り着けるようにしている。

## フォームの入手方法と切り替え方

確認済みのものと、そうでないもの：

- **確認済み（公式データ）：** フォームは属性や生息地が異なる独立したIndexエントリーとして公開されている。フォームのコレクションはAniilogエントリー上で種ごとにカウントされ、コンプリートボーナスが存在——Nimbiは4フォームすべてを収集すると**体力+3**を獲得し、「フォームを4つ集める」リサーチタスクも用意されている。図鑑側の仕様については[Anilogガイド](/ja/creatures/aniimo-dex/)を参照。
- **コミュニティのベータデータ：** **Morph Orb**というアイテムで、解放済みのフォーム間を切り替えられる。
- **未公開：** Cloudmist Formの具体的な入手方法、Morph Orbの入手手段、一部フォームがイベントや天候で制限されるかどうか。これらの空白は2026年9月16日のリリース後に埋まる予定——判明次第、このページ上部の日時を更新する。

## フォーム vs 進化 vs Prismana：三者比較表

この3つの類似システムはしょっちゅう混同される。きれいに整理すると：

| | フォーム | [進化](/ja/creatures/aniimo-evolution/) | [Prismana](/ja/guides/aniimo-prismana/) |
| :--- | :--- | :--- | :--- |
| 何が変わる？ | 見た目、場合により属性＋生息地 | 段階、ステータス、スキル | 色のレアリティ |
| ステータス | フォーム間で共通 | 段階ごとに上昇 | 変化なし |
| 方向性 | 水平（並列） | 垂直（成長） | 水平（見た目） |
| 例 | NimbiのCloudmist Form | Nimbi → Dreaple/Turbo | 虹色のNimbi |
| 併存可能？ | 可能——Prismanaのレアリティはどのフォームにも付き得る | 可能——進化後の段階にも公開済みなら独自のフォームがある | 可能 |

コミュニティから補足しておくと、公開データにはフォーム同士が排他になるという情報はなく、コレクションボーナスが存在するのはまさに全部集める前提だからこそだ。

## よくある質問

### アニモにおけるフォームとは？

フォームとは、アニモの種の公開済みバリエーションのこと。すべての生き物にはBasic Formがあり、一部には追加フォームが存在する——バイオームに合わせた異なる見た目、場合によっては第二属性、さらには別の生息地を持つこともある。公式Aniimo Indexは各フォームを独自のページを持つ独立エントリーとして公開している。

### Cloudmist Formとは？

Cloudmist FormはNimbiに公開されている3つのバリエーションのひとつ。風単一属性とNimbus Fieldsの生息地はそのまま、コミュニティの報告では、草ではなくSunny Daisyを好むため毛に金色がかるとされている。入手方法はまだ公開されていない。

### フォームは進化と同じ？

いいえ。進化は系統を上位へ進め、ステータスの上限を引き上げる——NimbiはDreapleまたはTurboへ進化する。フォームは同じ段階の並列バリエーションで、基礎ステータスはすべて共通。Rainstorm FormのNimbiとBasic FormのNimbiのステータスは完全に同一だ。

### フォームはPrismanaと同じ？

いいえ。Prismanaの虹個体は別システムの見た目レアリティで、Prismanaガイドで解説している。フォームは見た目と場合によって属性を変え、Prismanaは色のレアリティを変える。フォーム個体自体がPrismanaのレアリティで登場することもある。

### フォーム間の切り替え方法は？

コミュニティのベータデータでは、Morph Orbというアイテムで解放済みのフォーム間を切り替えられるとされている。オーブの入手方法に関する公式情報はまだ公開されておらず、判明次第このページを更新する。

### フォームでステータスは変わる？

いいえ。公式インデックスデータにより、種の全フォームは同じ基礎ステータス、ロール、体重帯、特性を共有することが確認されている。フォームが変え得るのは属性——NimbiのRainstorm Formは雷を、Plateau Formは氷を追加する——と、場合によっては生息地だ。
