## アニモにおけるパスファインダーのキャラクターカスタマイズ

アニモでは、プレイヤーはパスファインダーとして旅することになる。公式のゲームプレイ紹介映像やクローズドベータのテストフェーズから見る限り、プレイヤーキャラクターのカスタマイズは充実している様子で、近年のRPGの標準的な要素をしっかり踏襲した作りになりそうだ。キャラクター作成の初期段階では、顔の造形、髪型、髪色、ボイスなどの項目を調整できると見られる。ただし、スライダーの詳細な内容やプリセットの正確な上限については、正式リリースまでに変更される可能性が残っている。

エーデル大陸での冒険が進むにつれて、カスタマイズの選択肢はキャラクター作成画面の内容から大きく広がっていく見込みだ。開発陣は、クエストや探索、場合によってはシーズン制のバトルパスなどで獲得できる各種の防具セットや衣装の存在を示唆している。本作の核となるのはリアルタイムのアクションバトルと、ツワイン（Twine）システムを通じた生き物との絆づくりだ。そのため装備は、テンポの良い戦闘で実用性を保ちつつ、見た目も良く見えるものである必要がある。

| カスタマイズ項目 | 提供時期（想定） | 詳細・備考 |
| :--- | :--- | :--- |
| 顔の造形＆スライダー | キャラクター作成 | プリセットとスライダーは採用濃厚。詳細な深度は未発表。 |
| 髪型・髪色 | キャラクター作成＆サロン | トレーラーで複数のスタイルを確認済み。NPCサロンの実装も有望。 |
| 防具・衣装 | 進行／ゲーム内ショップ | 見た目が変化。ステータスボーナスも期待される。 |
| アクセサリー（帽子・バッグなど） | 探索＆イベント | パスファインダーのシルエットを個性化するのに使用。 |

アニモは基本プレイ無料のタイトルなので、ゲーム内で獲得できるコスチュームに加え、課金ショップで販売されるプレミアム衣装が混在するラインナップになるのは十分に予想できる。こうしたプレミアム要素がステータスにどう関わるのか――純粋な見た目変更なのか、それとも軽微なゲームプレイ上のメリットを伴うのか――については、FunPlusとPawprint Studioからまだ詳しい説明はない。

## 生き物のカスタマイズ

本作の真の主役は、絆を結ぶ魔法の生き物たちだ。生き物を捕まえるアクションRPGであるアニモでは、カスタマイズはこの相棒たちにも及ぶが、従来のRPGの装備品とは少し仕組みが異なる。Helmut、Emberpup、Eko、Eklue、Darklerといった生き物が登場するゲームプレイ映像からは、相棒たちが属性や戦闘での役割を反映した、それぞれ個性の異なる基本デザインを持つことがうかがえる。

生き物の能力を変化させる主な手段は、「ツワイン」と呼ばれる絆システムだ。これはどちらかというとステータスとアビリティの成長ツリーに近いが、生き物のカスタマイズにはコスチューム系のアクセサリーも含まれる可能性が高い。トレーラー映像では小さな装飾的なディテールも確認されており、コミュニティでは、パスファインダーが絆を結んだアニモに装備できる、解放型の帽子・アーマープレート・サドルバッグなどの登場が期待されている。

現時点で判明している、手持ちの生き物をパーソナライズする方法は次の通りだ。

| パーソナライズ項目 | 仕組みのタイプ | 入手方法 |
| :--- | :--- | :--- |
| 基本のビジュアル | 固定／世界観ベース | 生き物の種族とバリエーションに生まれつき備わるもの。 |
| アビリティ構成 | 成長要素 | ツワインの絆システムを通じて解放。 |
| コスチュームアクセサリー | アニモのカスタマイズ | クエスト、探索、イベントなどでの獲得が濃厚。 |
| 視覚効果／オーラ | 推測 | 終盤の進化や絆レベル最大に関連する可能性。 |

> **注記：** Pawprint Studioは、生き物がプレイヤーとともにリアルタイム戦闘に参加する様子を公開している。戦闘がアクション志向である以上、アニモに装備する装飾用アーマーは、ゲームバランスを保つために見た目だけの変化にとどまる可能性が高い。ただしこの点は、リリースが近づいてから公式に確認される必要がある。

## ハウジングと拠点建築

最近のオープンワールドRPGの大きな柱のひとつが専用の住空間であり、アニモもこの要素をしっかり取り込んでくると見られる。ハウジングシステムの正確な規模はまだ明らかにされていないものの、拠点建築は当然、プレイヤーが利用できるアニモカスタマイズの中でも最も幅広いもののひとつになるはずだ。家を建てて装飾することで、パスファインダーが休息を取ったり、手持ちの生き物を管理したり、協力プレイでマルチプレイヤーのフレンドと交流したりするための中央ハブとして機能する。

エーデル大陸の大自然から資材を集めて、家具や建築パーツ、装飾品をクラフトできると考えていいだろう。公開情報から見える鮮やかでカラフルなアートディレクションを考えると、ハウジングシステムには自由度の高い配置ツールが搭載され、こぢんまりとした農家風の家から広大なファンタジー屋敷まで、好きなようにデザインできるようになりそうだ。

*   **外観の建築：** 拠点のレイアウト、サイズ、建築様式をカスタマイズ。
*   **内装デザイン：** ベッド、テーブル、生き物の住処、クラフト用の作業台などを配置。
*   **造園：** 所有地のすぐ周辺にある地形や草木を改変。
*   **トロフィー：** 難易度の高いファンタジークエストやダンジョン的なコンテンツで集めた実績やレアアイテムを展示。

アニモが2026年のリリースに向けて開発を続けるなか、ケルンの gamescom（Gamescom）2026のようなイベントに足を運ぶファンは、拠点建築のメカニクスに特化した詳しい紹介を心待ちにしている。それまでは、これらのハウジング機能は「実装される可能性は非常に高いが、まだ確定していない」と考えておこう。

## 武器・装備・トランスモグシステム

アニモは本質的にアクションRPGであるため、パスファインダーはリアルタイム戦闘でさまざまな武器やアビリティを駆使することになる。それには堅牢な装備システムが必要になり、同時に、装備中のビルドにかかわらずキャラクターの見た目をスタイリッシュに保てる、ビジュアル面のカスタマイズも求められることになる。

公式のプレスリリースでは「トランスモグ（transmogrification）」システムについての詳しい言及はまだないが、これは最近の基本プレイ無料タイトルでは標準的な機能だ。トランスモグシステムがあれば、高ステータス装備の見た目を、お気に入りの低レベル衣装のデザインに上書きできる。キャラクターの個性とオープンワールド探索が重視されていることから、何らかの見た目上書きシステムは、リリース時か直後に実装される可能性が高い。
