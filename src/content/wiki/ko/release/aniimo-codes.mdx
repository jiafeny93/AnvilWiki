기본 플레이 무료 게임 출시에는 코드가 따라오기 마련이고, 애니모도 예외가 아닐 겁니다 — 하지만 지금 당장은 **사용할 수 있는 코드가 하나도 없습니다.** 게임은 2026년 9월 16일에 [전 세계 동시 출시](/ko/release/aniimo-release-date/)되며, 퍼블리셔 FunPlus는 출시 전 코드를 배포한 바 없습니다. 이 페이지가 출시 주간의 코드 허브입니다. 첫 코드가 등장하는 순간 아래 표가 채워지기 시작하고, 검증된 사용 절차도 함께 정리됩니다.

한 가지는 분명히 말해 둘 필요가 있습니다. **출시 전에 "작동하는 애니모 코드가 있다"고 주장하는 사이트, 영상, 댓글은 전부 클릭베이트이거나 사기입니다.** 기대작이 출시하기 전마다 가짜 코드 생성기가 나타나는데, 목적은 어그로 수형인 경우와 계정 도용인 경우 둘 중 하나입니다. 진짜 코드는 공식 채널에서만 나오고, 여기에는 검증을 거쳐 올라갑니다.

> **마지막 업데이트: 2026년 8월 29일** — 출시 전 에디션. 실제 코드 표는 출시일에 공개됩니다.

## 애니모 코드로 받을 수 있을 것으로 예상되는 보상

세부 보상은 TBA지만 장르의 관례는 확립돼 있습니다. [배틀 패스](/ko/release/aniimo-battle-pass/)와 코스튬 중심의 [수익 모델](/ko/release/aniimo-monetization/)을 갖춘 [기본 플레이 무료](/ko/release/aniimo-free-to-play/) 오픈월드 RPG인 만큼 현실적인 예상은 다음과 같습니다.

- **코스튬 보상** — 패스파인더 의상, 애니모 외형 변형, 이모트, 칭호.
- **소액의 유료 재화** — 기쁨은 주지만 [배틀 패스](/ko/release/aniimo-battle-pass/)를 통째로 건너뛸 분량은 아닙니다.
- **기간 한정 부스트** — 출시 축하 및 마일스톤 이벤트 기간의 경험치·자원 보너스.
- **마일스톤 기념 코드** — 사전예약이 전 세계 500만을 돌파했습니다. 출시 주간 기념 배포는 이 퍼블리셔의 정석 패턴입니다.

Pawprint Studio가 지금까지 지켜온 노선을 유지한다면, 코드가 **절대 주지 않을** 것도 있습니다. 바로 획득 가능한 크리처 그 자체입니다. [트와인 유대 시스템](/ko/creatures/aniimo-catching/)은 핵심 게임플레이 루프이고, 크리처를 코드 뒤에 가두면 스튜디오가 줄곧 홍보해 온 포획 철학 자체가 무너집니다.

## 애니모 코드 사용 방법

게임 내 사용 절차는 출시 전까지 TBA입니다. 같은 종류의 기본 플레이 무료 게임들이 처리하는 방식을 보면 다음 두 패턴 중 하나가 될 가능성이 높습니다.

1. **게임 내 메뉴 사용** — 설정 메뉴의 코드 입력란에 코드를 입력하거나 붙여넣으면 보상이 게임 내 우편함으로 지급되는 방식.
2. **공식 사이트 사용** — 공식 사이트의 코드 사용 페이지에 플랫폼 계정으로 로그인해 코드를 입력하고, 다음 게임 접속 시 보상을 받는 방식.

어느 쪽이든 출시일에 스크린샷과 함께 절차를 여기에 기록합니다. 플랫폼·지역 제한이 있다면 함께 표기합니다 — 모바일·PC·콘솔의 사용 절차가 서로 다른 게임은 드물지 않기 때문입니다.

## 코드 발표처 — 가짜 코드 걸러내는 법

같은 종류의 출시에서 공통적으로 나타나는 신뢰도 순서는 다음과 같습니다.

| 우선순위 | 출처 | 신뢰도 |
| :--- | :--- | :--- |
| 1 | 공식 애니모 디스코드 공지 채널 | 공식 |
| 2 | 공식 애니모 X · SNS 계정 | 공식 |
| 3 | 퍼블리셔(FunPlus) 캠페인 페이지 | 공식 |
| 4 | 모음 사이트(이 사이트 포함) | 1~3과 대조 필요 |

걸러야 할 가짜 코드 패턴은 이렇습니다. "사용을 위해 게임 계정으로 로그인하라"고 요구하는 사이트, 코드를 보여주기 전에 파일 다운로드나 설문 완료를 요구하는 페이지. 공식 코드 사용은 절대 이런 식으로 작동하지 않습니다. 비밀번호를 요구하는 코드는 전부 사기입니다. 피해 후 출시일에 로그인 문제가 생겼다면 [에러 코드 해결 가이드](/ko/release/aniimo-error-codes/)의 계정 보안 조치를 참고하세요. 첫걸음은 즉시 비밀번호 변경입니다.

## 출시 주간에 이 페이지를 즐겨찾기해야 하는 이유

출시 주간 코드는 수명이 짧습니다. 같은 종류의 게임에서 코드 대부분은 24~72시간 안에 만료되고, 가치 높은 기념 코드는 몇 시간 만에 끝나기도 합니다. 이 표는 코드가 나온 당일에 업데이트되고 만료 시각은 UTC로 표기합니다. 디스코드 기록을 뒤질 필요 없이 이 한 장으로 끝나는 구조입니다. 이미 챙겨 둔 [사전예약 보상](/ko/release/aniimo-pre-register/)과 함께라면 출시 주간이 어수선한 쫓기기가 아니라 정리된 체크리스트가 됩니다. 출시 당일 코드가 적용되지 않거나 게임에 접속되지 않으면 서버 문제부터 확인하세요. [서버 상태](/ko/release/aniimo-server-status/) 페이지에서 몇 초 만에 나만의 문제인지 전체 문제인지 판별할 수 있습니다.
