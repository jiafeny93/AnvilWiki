애니모가 정식 출시됐습니다 — PC(Steam·Epic), PS5, Xbox 버전이 2026년 9월 16일 [전 세계 출시](/ko/release/aniimo-release-date/)되었고, [모바일 버전](/ko/release/aniimo-mobile/)이 9월 23일 뒤따랐으며, 첫 기프트 코드도 그와 함께 등장했습니다. 이번 업데이트 기준 유효한 코드는 11개로, 합산하면 결코 작지 않은 초기 자산이 됩니다: 수만 Credits, Glimmer, 그리고 경험치 꽃과 Aniipod 소모품 한 보따리.

이전부터 있던 경고는 그대로 유효합니다: **진짜 코드는 절대 로그인 정보를 요구하지 않습니다.** 대형 출시마다 가짜 "코드 생성기" 사이트가 나타나 클릭이나 계정 탈취를 노립니다. 아래 표는 여러 코드 사이트에서 교차 검증된 코드만 실으며, 코드가 만료되면 갱신합니다.

> **마지막 업데이트: 2026년 9월 24일** — 유효 코드 11개. 어느 것도 만료일이 공표되지 않았습니다. 출시 기간 코드는 수명이 짧은 편이니 서둘러 사용하세요.

## 애니모 코드로 받을 수 있는 보상

출시 코드는 네 종류의 아이템을 주며, [이들](/ko/release/aniimo-free-to-play/) 탐험 초반 내내 유용합니다:

- **Glimmer** — [가챠](/ko/release/aniimo-gacha/)와 코스메틱 경제를 움직이는 프리미엄 통화. 코드로 주는 양은 적지만 공짜인 것만으로 이득입니다.
- **Credits** — 일상 업그레이드와 구매에 쓰는 일반 통화. 가장 후한 두 코드를 합쳐 30,000을 받을 수 있습니다.
- **Growth Flowers** — 크리처 레벨업을 빠르게 하는 경험치 아이템. `ANIIMOGIFT` 하나로 10개를 받아 새 크리처가 한 발 앞서 출발합니다.
- **Aniipod과 Aniipod Pro** — 소모품 아이템. Pro 등급이 더 희귀합니다.

이번 업데이트 기준 코드가 주지 **않는** 것: 전용 포획 가능 크리처. 위 표의 보상은 모두 소모품이나 통화이며, [트와인 유대 시스템](/ko/creatures/aniimo-catching/)을 통한 포획이 크리처 획득의 유일한 길이라는 설계 노선은 출시 후에도 유지되고 있습니다.

## 애니모 코드 사용 방법

모든 플랫폼에서 게임 내 사용입니다. 초반 튜토리얼 구역을 먼저 마쳐야 합니다 — 그 전까지 일시정지 메뉴는 잠겨 있습니다.

1. 애니모를 실행하고 **일시정지 메뉴**가 열릴 때까지 진행(튜토리얼 구역 끝).
2. 일시정지 메뉴를 열고 **톱니바퀴 아이콘**(설정) 클릭.
3. **Account** 탭 선택.
4. **Gift Code Redemption** 선택.
5. 위 표의 코드를 입력하거나 붙여넣기 — 대소문자 주의.
6. **Redeem** 클릭. 보상은 **인벤토리**에 바로 지급 — 우편함 단계 없음.

코드가 거부되면 세 가지를 순서대로 확인하세요: 철자와 대소문자, 튜토리얼 완료 여부, 이미 사용한 코드인지 — 각 코드는 계정당 한 번만 사용할 수 있습니다. 사용 자체가 오류 나거나 게임이 접속되지 않으면 먼저 [서버 상태](/ko/release/aniimo-server-status/) 페이지로 서버 문제를 배제하고, 나머지는 [오류 코드 수정 목록](/ko/release/aniimo-error-codes/)을 참고하세요.

## 스쿼드 코드는 별개 시스템

기프트 코드 `aniimotogether`와 Aniimo Together의 **스쿼드 코드**는 다른 것으로, 혼동하기 쉽습니다. 스쿼드 코드는 6자리 초대 코드로 Aniimo Together 웹 이벤트에서 사용합니다: 입력하면 다른 플레이어의 스쿼드에 가입할 수 있고, 내 코드를 공유해 인원을 모을 수도 있습니다. 스쿼드는 최대 6인이며 인원이 늘 때마다 공유 **창고 용량**이 늘고, 6명을 채우면 전원에게 보너스 Aniipod가 지급됩니다. 무작위 6자리 문자열을 "기프트 코드"로 실은 사이트가 있다면 그것은 스쿼드 초대장입니다 — 진짜 기프트 코드는 위 표의 문자열입니다.

## 새 코드 발표처 — 가짜 코드 걸러내는 법

지금까지의 출시 코드 흐름을 기준으로 한 신뢰도 순서입니다:

| 우선순위 | 출처 | 신뢰도 |
| :--- | :--- | :--- |
| 1 | 공식 Discord — 공지 채널 | 공식 |
| 2 | 공식 X / SNS 계정 | 공식 |
| 3 | 퍼블리셔(FunPlus) 캠페인 페이지 | 공식 |
| 4 | 애그리게이터 사이트(이 사이트 포함) | 1-3과 대조 필요 |

가짜 코드의 전형: 게임 계정 로그인을 요구하거나, 파일을 받게 하거나, 설문·오퍼를 완료해야 코드를 보여주는 사이트. 공식 사용 흐름은 절대 그렇지 않습니다 — 실제 흐름은 이전 섹션의 6단계뿐이며 전부 게임 클라이언트 안에서 끝납니다. 비밀번호를 요구하는 코드는 사기입니다 — 이미 가짜 사이트에 자격 증명을 입력했다면 첫 단계는 즉시 비밀번호 변경이고, [오류 코드 수정 목록](/ko/release/aniimo-error-codes/)에 계정 보안 정리법을 정리해 두었습니다.

## 이 페이지를 즐겨찾기해야 하는 이유

출시 기간 코드는 수명이 짧습니다 — 비슷한 게임들은 며칠 안에 코드를 만료시키는 게 보통이고, 위 11개 중 어느 것도 만료일이 공표되지 않았습니다. 이 표는 업데이트마다 전 코드를 다시 확인하므로, Discord 기록을 뒤지는 대신 이 한 곳만 보면 됩니다. 이미 받아둔 [사전 등록 보상](/ko/release/aniimo-pre-register/)과 함께 보면 첫 플레이가 허둥지둥 몰아치기가 아니라 깔끔한 체크리스트가 됩니다.
