## 애니모 코드 목록 (2026년 8월)

### 사용 가능한 코드

현재 **사용 가능한 애니모 선물 코드는 없습니다**. 게임이 아직 정식 출시 전이라 2026년 9월 16일 글로벌 출시를 앞두고 마무리 준비 중이며, Pawprint Studio는 지금까지 사용 가능한 코드를 공개한 적이 없어요.

출시 전 구간에서는 흔한 일입니다. 기본 플레이 무료(무료) 게임은 대부분 출시 주간, 주요 사전예약 마일스톤, 콜라보 이벤트 때 첫 선물 코드를 배포해요. 첫 코드가 공개되는 즉시 아래 표를 채워드리겠습니다.

### 만료된 코드

아직 코드가 하나도 공개되지 않았기 때문에 만료된 코드도 없습니다. 코드 로테이션이 시작되면 만료된 코드를 이곳으로 옮겨서 어떤 코드가 아직 시도해 볼 만한지 한눈에 확인할 수 있게 해드릴게요.

## 애니모 코드 사용 방법

인게임 코드 사용 시스템은 아직 열리지 않았기 때문에, 아래 단계는 각 플랫폼에서 비슷한 게임들이 사용하는 표준 흐름을 기준으로 작성했어요. 출시와 함께 시스템이 열리면 정확한 메뉴명을 확인해 업데이트하겠습니다.

### PC (Steam / Epic), PS5, Xbox에서

1. 애니모를 실행하고 계정에 로그인합니다.
2. **설정(Settings)** 메뉴(톱니바퀴 아이콘) 또는 플레이어 프로필을 엽니다.
3. **코드 사용(Redeem Code)**, **선물 코드(Gift Code)** 또는 **교환(Exchange)** 옵션을 찾습니다.
4. 코드를 표시된 그대로 정확히 입력하세요 — 코드는 대소문자를 구분하는 경우이 대부분입니다.
5. 확인 후 인게임 우편에서 보상을 수령하세요.

### 모바일 (iOS / Android)에서

1. 게임 로비에서 **아바타/프로필**을 탭합니다.
2. **설정**을 열고 **코드 사용** 항목을 찾습니다.
3. 코드를 입력하거나 붙여넣고 **확인**을 탭합니다.
4. 보상은 인게임 우편으로 도착하며, 보통 몇 분 안에 받을 수 있어요.

일부 모바일 게임은 브라우저에서 계정 로그인 후 코드를 입력할 수 있는 웹 사용 포털도 제공합니다. 애니모에도 생기면 이곳에 링크를 걸어드릴게요.

## 지금 바로 받을 수 있는 무료 보상

무료 아이템의 출처는 코드만이 아닙니다. 첫 코드가 나오기를 기다리는 동안에도 아래 보상은 이미 받을 수 있어요:

- **사전예약 마일스톤:** 공식 웹사이트에서 사전예약하면 커뮤니티 전체가 함께 보상을 받습니다. 확정된 단계로는 500만 명 달성 시 **Glimmer x200**, 1,000만 명 시 **Aniipod Ultra x2**, 1,500만 명 시 한정 **Companion Promise 프로필 프레임**, 2,000만 명 시 **Sunlit Meadow 한정 의상**이 있습니다. 자세한 내용은 [사전예약 가이드](/ko/release/aniimo-pre-register/)를 참고하세요.
- **베타 참여 보상:** 클로즈드 베타에 참여한 플레이어는 출시 시점에 전용 보상을 받는 경우가 많습니다. 테스터가 무엇을 가져가는지는 [애니모 베타 가이드](/ko/release/aniimo-beta/)에서 확인하세요.
- **출시 기념 이벤트:** 출시 주간 로그인 이벤트와 축하 퀘스트는 과거에 프리미엄 재화를 지급해 왔습니다. 출시일 당일 기대할 수 있는 내용은 [출시일 허브](/ko/release/aniimo-release-date/)에서 추적하고 있습니다.

## 새 애니모 코드가 가장 먼저 공개되는 곳

첫 코드가 나오면 거의 항상 공식 채널을 통해 가장 먼저 발표됩니다:

- 공식 **애니모 Discord 서버** — 개발진이 공지사항과 커뮤니티 이벤트를 올리는 곳입니다.
- 공식 **X (Twitter)** 계정 — 마일스톤 축하와 패치 노트를 공유합니다.
- 공식 **YouTube** 영상 — 트레일러 프리미어 설명란이나 프리미어 채팅에서 코드가 공개되는 경우도 있습니다.

콘텐츠 크리에이터와 팬 사이트(이 위키 포함)도 코드를 빠르게 퍼 나르지만, 정확한 출처는 항상 공식 채널입니다. 공식 발표로 추적할 수 없는 댓글이나 포럼의 코드는 조심하는 게 좋습니다 — 큰 게임 출시 즈음에는 가짜 코드 사기가 흔합니다.

## 애니모에 선물 코드가 있는 이유

선물 코드는 기본 플레이 무료(무료) 게임에서 표준적으로 쓰이는 유저 유지·축하 수단입니다. 애니모는 가챠 요소가 있는 무료 타이틀이며, 그 수익 모델상 주기적인 코드 배포가 매우 유력해요 — 퍼블리셔는 사전예약 마일스톤, 버전 업데이트, 콜라보, 소셜 미디어 팔로워 목표 달성을 축하하는 데 코드를 사용합니다.

애니모가 무엇을 판매하고 무엇이 무료로 남는지 전체적으로 알고 싶다면 [수익 모델 가이드](/ko/release/aniimo-monetization/)와 [배틀패스 분석](/ko/release/aniimo-battle-pass/)을 읽어보세요.

## 자주 묻는 질문

### 애니모 코드는 모든 플랫폼에서 작동하나요?

대부분의 크로스플랫폼 게임에서 선물 코드는 기기가 아닌 계정에 적용되기 때문에, PC에서 사용한 코드는 같은 계정의 모바일·콘솔에서도 효과가 있습니다. 크로스플랫폼 진행 상황 공유가 애니모의 핵심 기능이니 계정 단위 보상이 예상되지만, 출시 시점에 확인해 보겠습니다.

### 코드 생성기나 무료 코드 사이트는 안전한가요?

아니요. "애니모 코드 생성기"는 합법적으로 존재하지 않습니다. 코드를 받으려고 로그인하거나 설문조사를 하라고 하는 사이트는 전부 사기입니다. 공식 애니모 채널로 거슬러 올라가거나 커뮤니티에서 확인된 코드만 믿으세요.

### 애니모 코드는 얼마나 오래 유효한가요?

비슷한 게임의 선물 코드 대부분은 몇 주 후 만료되며, 출시 주간 코드 중 일부는 며칠 만에 만료됩니다. 코드를 보는 즉시 사용하세요 — 이 페이지를 즐겨찾기에 넣고 큰 업데이트가 있을 때마다 확인하는 걸 권합니다.

### 9월 16일 글로벌 출시 때도 코드가 나오나요?

가능성이 매우 높습니다. 출시 축하는 기본 플레이 무료 게임에서 선물 코드가 배포되는 가장 흔한 경우이고, 애니모의 2026년 9월 16일 글로벌 출시는 남은 일정 중 가장 큰 마일스톤이니까요.

## FAQ

**지금 나와 있는 애니모 코드가 있나요?**

아직 공개된 선물 코드는 없습니다. 애니모는 2026년 9월 16일 글로벌 출시를 앞둔 마지막 준비 단계에 있으며, 개발진은 아직 사용 가능한 코드를 공개하지 않았어요. 첫 코드가 나오면 몇 시간 안에 이 페이지를 업데이트하겠습니다.

**애니모 선물 코드는 언제 공개되나요?**

비슷한 기본 플레이 무료(무료) 게임의 출시 방식을 보면, 첫 애니모 코드는 2026년 9월 16일 글로벌 출시 전후와 사전예약 캠페인, 베타 이벤트, 시즌 업데이트 같은 마일스톤 때 가장 유력하게 등장할 것으로 보입니다.

**애니모 코드는 어디서 가장 먼저 공개되나요?**

새 코드는 보통 공식 애니모 X (Twitter) 계정, 공식 Discord 서버, YouTube 영상에서 게시됩니다. 해당 채널을 팔로우하거나 이 페이지를 주기적으로 확인하는 게 만료 전에 코드를 잡는 가장 빠른 방법입니다.

**애니모에서 코드는 어떻게 사용하나요?**

코드 사용 시스템이 열리면 예상되는 흐름은 게임 실행 → 설정 또는 프로필 이동 → 코드 사용/선물 코드 옵션 찾기 → 코드를 그대로 입력 → 우편으로 보상 수령 순입니다. 정확한 메뉴는 플랫폼마다 다를 수 있으며 출시 시점에 이곳에서 확인해 드리겠습니다.

**코드가 없을 때 무료 보상은 어떻게 받나요?**

공식 웹사이트에서 사전예약하고 커뮤니티 마일스톤을 달성하면 됩니다. 사전예약 500만 명 달성 시 모두 Glimmer x200, 1,000만 명 시 Aniipod Ultra x2, 1,500만 명 시 한정 Companion Promise 프로필 프레임, 2,000만 명 시 Sunlit Meadow 한정 의상을 받습니다.
