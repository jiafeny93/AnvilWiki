收集 Aniimo 图鉴是 Aniimo 的核心冒险玩法。这款由 Pawprint Studio 打造的次世代开放世界生物[捕捉](/zh/creatures/aniimo-catching/) ARPG 即将上线，作为一名寻路者，你将在广袤的伊笛尔大陆上展开旅程，不断发现、结契魔法生物，并将它们记录进你专属的 Aniimo 图鉴。与传统的回合制捕捉游戏不同，Aniimo 采用即时战斗，并配有独特的"Twine"联结系统，彻底改变了你与野生生物的互动方式。社区通常把这本图鉴简称为 **Anilog**——你也会看到 **Aniilog** 的拼法，而官网则将其定名为 **Aniimo Index**；本攻略中三种称呼可互换使用。官方图鉴目前已公布首发阵容，包含每只生物的属性、定位、基础数值和技能表。本攻略汇总了图鉴机制、所有已确认生物，以及 2026 年 9 月 16 日发售前的联结玩法详解。

## Anilog 是什么？Aniilog、Aniimo Index 与图鉴详解

搜索"aniimo anilog"的你，和其他搜索"aniimo dex"的玩家找的是同一个东西——记录你发现并结契的每只生物的收集图鉴。这个名称在社区中形成了三种拼法，指的都是同一套系统：

| 名称 | 常见场景 |
| :--- | :--- |
| **Anilog** | 社区视频和大部分玩家讨论 |
| **Aniilog** | 粉丝 Wiki 和数据库（两个 i） |
| **Aniimo Index / 百科** | wiki.aniimo.com 的官方定名 |

有两点需要澄清。首先，Anilog **并不是一个独立 App**——它内置于游戏中，任何商店都没有官方伴生应用。其次，图鉴条目不只是打卡清单：每个条目会记录形态变体的收集进度和完成奖励，因此集齐一页 Aniilog（例如收齐所有已知 [Nimbi 形态](/zh/guides/aniimo-forms/)）会带来超出捕捉本身的回报。

## Twine 联结系统如何影响 Aniimo 图鉴

在 Aniimo 中，图鉴不只是一本静态的百科全书——它真实反映你与所遇生物之间的即时联结。让这款游戏脱颖而出的核心机制就是"Twine"联结（Twine）系统。寻路者不再是简单削弱一只生物然后扔出道具，而是与伊笛尔的魔法兽建立深厚的羁绊。

通过 Twine 联结系统将生物加入图鉴后，你能做的远不止在菜单里观察它。根据官方实机演示，Twine 联结系统让你可以真正透过结契生物的视角看世界，并在快节奏的即时动作战斗中使用它们的专属能力。这意味着集齐图鉴不只是"全收集"，更是策略性地打造一支能力多样、物理与元素兼备的队伍，随时在野外调用。图鉴 UI 具体如何追踪联结等级和能力解锁尚待观察，但预计会是一套深度整合的进度系统。

靠预告片猜谜的时代结束了——官方 Aniimo Index 现已公布全部 94 个首发条目（No.001 至 No.093 外加两个悬念位），附带确认的属性、定位、基础数值、栖息地和完整技能表。阵容中的几个亮点：

每个条目——从 No.001 到两个未公开的悬念位——都在我们的 [Aniimo 生物全集](/zh/creatures/aniimo-creatures-list/)中拥有档案页，首个活动传说生物 [Irisalis](/zh/creatures/aniimo-irisalis/) 也已有专属页面。部分 Aniimo 还会以其他形态出现（例如 Nimbi 的 Cloudmist Form 形态）——详见 [Aniimo 形态攻略](/zh/guides/aniimo-forms/)。

探索伊笛尔多样的生态区是找到这些生物的关键。有些 Aniimo 领地意识极强，镇守特定地下城或开放世界 Boss；另一些则成群漫步在平原之上。

## 追踪并集齐你的 Aniimo 图鉴

在一款大型开放世界 ARPG 中集齐图鉴，需要与老式同类游戏不同的思路。由于 Aniimo 采用即时战斗且没有随机遭遇，编撰图鉴将高度依赖探索、潜行和环境意识。

根据开发者演示，寻路者大致会这样追踪和捕获新条目：

| 玩法机制 | 对 Aniimo 图鉴的预期影响 |
| :--- | :--- |
| **开放世界刷新** | 生物自然出现在世界中；集齐图鉴依赖各生态区的探索。 |
| **即时交战** | 你需要在动作战斗中主动战斗、闪避并与生物结契，而非在菜单中操作。 |
| **Twine 联结** | 捕捉与战斗中或战斗后建立羁绊挂钩，可能带来独特的捕捉小游戏或机制。 |
| **奇幻任务与联机合作** | 部分稀有 Aniimo 图鉴条目可能需要多人协作才能发现或击败。 |

穿越伊笛尔时，你将借助已结契的 Aniimo 来跨越地形——比如飞行或游泳——从而打开此前与世隔绝的区域，那里往往藏有稀有图鉴条目。

## Aniimo 图鉴中的进化与成长

进化是任何生物捕捉游戏的标配，官方图鉴现已公布每只生物的进化树。升级与主动战斗挂钩，而非被动回合制对战，且不少进化线存在分叉——例如 Nimbi 在最终阶段会分化为 Dreaple 或 Turbo。

你的 Aniimo 图鉴条目不会再通过被动的回合制对战获取经验，而是大概率需要参与实时连招、施展各自的元素能力并在开放世界遭遇战中存活下来才能进化。玩家普遍期待某些生物会拥有分支进化路线、隐藏条件，或需要特定道具才能进入下一阶段。由于游戏包含奇幻任务和联机[多人](/zh/guides/aniimo-multiplayer/)玩法，某些进化甚至可能需要与其他寻路者交易或参与特殊世界事件。

随着 2026 年完整版发售临近，Pawprint Studio 预计将公布进化树的具体运作方式、数值成长曲线，以及 Twine 联结伙伴的等级上限。

## 常见问题

### Aniimo 图鉴是什么？

Aniimo 图鉴是游戏内的生物图鉴，寻路者在伊笛尔大陆上遇到的魔法生物、建立的联结都会记录其中。它追踪你收集的生物、它们的能力，以及通过 Twine 联结系统形成的联结等级。

### Aniimo 中的 Anilog（Aniilog）是什么？

### 发售时 Aniimo 图鉴里有多少生物？

### Aniimo 中捕捉生物是怎么运作的？

是的，Aniimo 包含联机合作和多人奇幻任务。你可以与其他寻路者一同探索开放世界、参与即时战斗并集齐 Aniimo 图鉴。
